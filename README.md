# SIRA — An Awareness-Driven Accessibility Model of Epidemic Dynamics

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)

Reproducible code and figures for:

> A. Alsammani and M. Mohammed, *"Long-term Coexistence of Epidemics and Risk Awareness: Impacts of Adaptive Human Response and Fatigue,"* submitted to **BIOMATH**.

The manuscript studies a susceptible–infected–recovered–aware (**SIRA**) model in which a population-level awareness index moves susceptible and infectious individuals between *accessible* and *inaccessible* behavioral states, rather than rescaling the transmission rate directly. This repository is the complete, executable record of the paper's numerics: it implements the model, locates and verifies every equilibrium and stability result stated in the text, and regenerates every figure in the manuscript and in the point-by-point response to the referee report, from first principles and with no intermediate data files.

## Start here

**[`SIRA_reproducibility.ipynb`](SIRA_reproducibility.ipynb)** is the primary entry point: a single, self-contained Jupyter notebook that combines the model, the theory, the numerics, and an interpretation of every figure into one readable document. Reading it top to bottom, without running any code, is a complete walkthrough of the paper's quantitative content; running it top to bottom regenerates every figure and checks every number the paper reports against an explicit `assert`.

## Quick start

```bash
git clone https://github.com/aalsammani/sira-epidemic-awareness.git
cd sira-epidemic-awareness
pip install -r requirements.txt
jupyter notebook SIRA_reproducibility.ipynb
```

or, with conda:

```bash
conda env create -f environment.yml
conda activate sira
jupyter notebook SIRA_reproducibility.ipynb
```

Running the notebook (`Kernel → Restart & Run All`) takes roughly two minutes on a single modern CPU core and requires no GPU, no external data, and no network access. Everything the notebook produces — figures and JSON summary files — is written under `figs/` and the repository root.

To reproduce a specific figure or scan from the command line instead of the notebook:

```bash
python figures.py           # all nine manuscript figures
python figures.py 5 8       # only Figures 5 and 8
python response_figures.py  # all four response figures and both scans
```

## The model in brief

$$S_a+S_u+I_a+I_u+R=1,\qquad A\in[0,1]$$

Susceptible and infected individuals are each split into *accessible* ($S_a$, $I_a$) and *inaccessible* ($S_u$, $I_u$) states. Transmission at rate $\beta$ occurs only between $S_a$ and $I_a$. A population-level awareness index $A$ is generated by prevalence at rate $\rho$ and decays through behavioral fatigue at rate $\omega$; awareness in turn governs the rates at which individuals move between accessible and inaccessible states. The full system is

$$
\begin{aligned}
\dot S_a&=(1-A)\mu-\beta S_aI_a+\kappa_2(A)S_u-\kappa_1(A)S_a-\mu S_a, &
\dot S_u&=A\mu+\kappa_1(A)S_a-\kappa_2(A)S_u-\mu S_u,\\
\dot I_a&=\beta S_aI_a-\delta_1(A)I_a+\delta_2(A)I_u-(\gamma+\mu)I_a, &
\dot I_u&=\delta_1(A)I_a-\delta_2(A)I_u-(\gamma+\mu)I_u,\\
\dot R&=\gamma(I_a+I_u)-\mu R, &
\dot A&=\rho(I_a+I_u)(1-A)-\omega A,
\end{aligned}
$$

with $\kappa_1(A)=\kappa_1^0A$, $\kappa_2(A)=\kappa_2^0(1-A)$, $\delta_1(A)=\delta_1^0A$, $\delta_2(A)=\delta_2^0(1-A)$. Full derivations, theorems, and proofs are given in the manuscript; the notebook restates the key results alongside the code that verifies them numerically.
